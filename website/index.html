Built for repeated and concurrent work

Reuse context and batch requests

Continuous batching and paged KV caching with Radix prefix sharing are enabled by default. Optional speculative decoding offers another path to lower latency on supported models.

Explore serving features →

Use more of your hardware

Selected architectures support multi-GPU layer placement, tensor parallelism and multi-node execution. SSD-backed expert offload can make selected large MoE models fit beyond RAM.

Check scaling support →

Performance you can check

Recent records: DeepSeek V4.1 Flash 1017 on five A40s reaches 3.23× the reference prefill rate with exact TP5 at a ~1.8K prompt; Muse Spark on ten A40s reaches 1.40× solo TP decode against the matching reference mode. Models, quantization and timing methods differ; see the full conditions and the quality cost of default approximate YOCO.
