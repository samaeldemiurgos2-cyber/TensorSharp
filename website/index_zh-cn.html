TensorSharp

本地 AI，原生 .NET。

用同一个 C# 推理引擎运行文本与多模态模型、生成图像和视频，并构建智能体工作流。通过 CLI、浏览器聊天、兼容 Ollama 与 OpenAI 的 API，或你自己的 .NET 应用使用它。

TensorSharp 能做什么

从第一次本地聊天，到提供模型服务、调用工具的应用。

文本与多模态推理

使用 Gemma、Qwen、DeepSeek、GLM 等模型聊天、推理，处理图像、音频和文档。可用的输入类型取决于模型。

浏览文本模型 →

图像与视频生成

用 Qwen-Image 2.1 与 8 步 Turbo 生成和编辑图像，支持蒙版编辑与兼容的 LoRA 插件。用 LTX 2.5 或 MiniMax-H3 联合生成视频与立体声音频，或用 Wan 生成视频。

浏览媒体模型 →

个人知识库

把文件、文件夹与已保存聊天导入本地集合，检索文档、OCR 与媒体派生文本，并在回答中追溯引用来源。

建立可复用资料库 →

面向多轮对话与并发任务

复用上下文，批量处理请求

默认启用连续批处理、分页 KV 缓存和 Radix 前缀共享。支持的模型还可选择推测解码，以进一步降低延迟。

发挥更多硬件的作用

部分架构支持多 GPU 层分布、张量并行和多节点执行。基于 SSD 的专家卸载可让部分大型 MoE 模型在权重超过内存容量时运行。

可核查的性能数据

近期记录：DeepSeek V4.1 Flash 1017 在五张 A40 上，约 1.8K 提示的精确 TP5 prefill 为参照的 3.23×；Muse Spark 在十张 A40 上，单请求 TP decode 为对应参照模式的 1.40×。模型、量化与计时方法不同；查看完整条件及默认近似 YOCO 的质量代价。
